# Antigravity 제15회 변호사시험 풀이 지시문 v4

아래 지시문은 Antigravity에 그대로 넣기 위한 제15회 변호사시험 풀이 컨텍스트다. 목적은 정답 암기가 아니라, 문제 원문과 v4 RAG 컨텍스트를 이용해 각 문항을 직접 풀고 파일로 저장하는 것이다.

## 사용할 자료

- 문제 폴더
  - `15th_split/civil_law`
  - `15th_split/public_law`
  - `15th_split/criminal_law`
- RAG 컨텍스트
  - `round15_rag_contexts_v4_20260625`
- 전체 참고 문서
  - `bar_exam_reference.md`
- 출력 폴더
  - `15th_solved_v4/civil_law`
  - `15th_solved_v4/public_law`
  - `15th_solved_v4/criminal_law`

기존 `14th_solved` 파일은 JSON 저장 형식만 참고한다. 제15회 정답, 해설, 채점표, 이미 풀린 답안은 절대 참고하지 않는다.

## 금지 사항

- 공식 정답을 검색하지 않는다.
- 웹 검색으로 해설 블로그, 학원 해설, 정답표를 찾지 않는다.
- 기존 solved 파일에서 제15회 답을 베끼지 않는다.
- 문제를 풀기 전에 선택지 번호를 감으로 고르지 않는다.
- RAG의 자동 `선지별 근거 후보`를 최종 결론으로 곧장 쓰지 않는다.

공식 법령, 대법원, 헌법재판소 URL은 RAG 문서 안에 포함된 경우 법리 확인용으로만 사용한다.

## 필수 풀이 절차

각 문항마다 아래 순서를 반드시 지킨다.

1. 문제 파일을 연다.
2. 같은 과목과 번호에 대응하는 `round15_rag_contexts_v4_20260625/qNNN_과목.md`를 연다.
3. 문제 방향을 한 줄로 확정한다: `옳은 것`, `옳지 않은 것`, `O/X 조합`, `개수형` 중 무엇인지 표시한다.
4. 모든 지문을 `ㄱ`, `ㄴ`, `ㄷ`, `ㄹ`, `ㅁ` 단위로 추출한다.
5. `v4 수동 보강 포인트`가 있으면 자동 판례 후보보다 우선 적용한다.
6. 각 지문에 대해 아래 표를 만든다.

```markdown
| 지문 | 판단 | 근거 | 확신도 |
|---|---|---|---|
| ㄱ | O/X | 적용 법리와 판례 | 상/중/하 |
```

7. 문제 방향에 맞춰 목표 지문 집합을 적는다.
   - 예: `옳지 않은 것: ㄱ, ㄷ`
   - 예: `옳은 것: ㄴ, ㄷ`
8. 번호 선택지 ①~⑤를 원문 그대로 다시 적고, 각 번호의 지문 집합을 목표 지문 집합과 비교한다.
9. 목표 지문 집합과 정확히 같은 번호만 답으로 고른다.
10. 저장 직전에 한 번 더 검산한다: 선택한 번호의 지문 집합이 목표 지문 집합과 다르면 답을 수정한다.

## 저장 형식

각 문항마다 풀이 markdown과 solved JSON을 모두 저장한다.

Markdown 예시:

```markdown
# civil_law_01 풀이

## 문제 방향
옳지 않은 것을 모두 고르는 문제

## 지문 판단
| 지문 | 판단 | 근거 | 확신도 |
|---|---|---|---|
| ㄱ | X | ... | 상 |

## 목표 지문 집합
옳지 않은 것: ㄱ, ㄷ

## 선택지 대조
① ㄷ - 불일치
② ㄱ, ㄴ - 불일치
③ ㄱ, ㄷ - 일치

## 최종 검산
선택지 ③의 지문 집합은 ㄱ, ㄷ이고 목표 지문 집합과 일치한다.
```

JSON은 `14th_solved`의 스키마를 따른다. 스키마가 불명확하면 최소한 아래 필드를 포함한다.

```json
{
  "question_id": "civil_law_01",
  "answer": 3,
  "selected_letters": ["ㄱ", "ㄷ"],
  "question_direction": "옳지 않은 것",
  "confidence": "high",
  "reasoning_file": "civil_law_01_solution.md"
}
```

## v4 RAG 사용 규칙

- `round15_rag_contexts_v4_20260625`를 우선 사용한다. v2나 v3는 v4에 파일이 없을 때만 참고한다.
- `v4 수동 보강 포인트`가 있으면 그 섹션을 가장 먼저 읽고 적용한다.
- 자동 후보와 수동 보강이 충돌하면 수동 보강 및 공식 URL을 우선한다.
- 수동 보강은 정답 번호가 아니라 법리 판단을 보강한 것이다. 그래도 반드시 선택지 원문과 대조해야 한다.
- 조합형 문제에서는 O/X 결론이 맞아도 번호 매칭을 틀릴 수 있으므로, 마지막 검산을 생략하지 않는다.

## 특히 주의할 문항

이번 v4에서 보강한 문항은 반드시 `v4 수동 보강 포인트`를 먼저 적용한다.

- 공법: `q007_공법.md`, `q011_공법.md`
- 형사법: `q023_형사법.md`, `q030_형사법.md`
- 민사법: `q009_민사법.md`, `q017_민사법.md`, `q019_민사법.md`, `q020_민사법.md`

다음 문항은 v3에서 이미 보강이 충분했으나 선택지 매칭 오류가 발생할 수 있으므로, 번호 대조를 더 엄격히 한다.

- 형사법: `q010_형사법.md`, `q025_형사법.md`

## 실패 패턴 방지

- `옳은 것`과 `옳지 않은 것`을 뒤집지 않는다.
- ㄱ~ㅁ O/X 판단이 끝나기 전에는 번호를 고르지 않는다.
- 선택지 원문을 기억으로 재구성하지 않는다.
- 같은 법리의 원칙과 예외가 같이 나오면 예외 요건부터 확인한다.
- 공동피고인, 전문법칙, 공소기각 판결/결정, 포괄일죄, 채권자대위, 변제자대위 문제는 지위와 절차시점을 분리해서 판단한다.

## 실행 지시

제15회 변호사시험 150문항을 과목별로 하나씩 직접 풀고 저장한다. 속도를 내되, 각 문항마다 O/X 표와 선택지 집합 검산은 생략하지 않는다. 불확실한 문항은 `confidence`를 낮추고 근거를 명시하되, 반드시 최종 답을 하나 선택한다.
