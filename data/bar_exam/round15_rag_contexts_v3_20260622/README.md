# 제15회 변호사시험 RAG 컨텍스트 v3

이 폴더는 `round15_rag_contexts_v2_20260619`를 기준으로 복사한 뒤, Gemini 풀이에서 실제로 틀린 공법 2문항과 형사법 8문항을 수동 보강한 v3입니다.

문제와 선택지는 포함하지만, 문항별 정답 번호나 채점값은 넣지 않았습니다. 모델이 답을 외워 맞히는 것이 아니라, 문제 문구와 컨텍스트의 법리로 결론을 도출하게 하려는 목적입니다.

## v3 생성 방식

1. `data/bar_exam/round15_rag_contexts_v2_20260619` 전체를 `data/bar_exam/round15_rag_contexts_v3_20260622`로 복사했습니다.
2. 모든 문서 제목의 `v2` 표기를 `v3`로 바꾸었습니다.
3. 사용자 피드백에서 오답으로 확인된 파일만 직접 열어 문제 문구와 선지 구조를 다시 읽었습니다.
4. 자동 검색 후보가 빗나간 부분을 덮기 위해 각 오답 파일의 `선지 분해` 바로 뒤에 `v3 수동 보강 포인트` 섹션을 추가했습니다.
5. 헌법재판소, 국가법령정보센터, 로컬 `legalize-kr`, 로컬 `../precedent-kr`를 대조해 법리 분기와 공식 URL을 정리했습니다.
6. 맞은 것으로 확인된 공법ㆍ형사법 문항과 아직 오답 피드백이 없는 민사법 문항은 본문을 유지했습니다.

## v3에서 고친 문제 유형

- 헌재 다수의견과 반대의견을 뒤집어 읽은 경우
- 일반 인터넷 실명제와 공공기관 게시판 본인확인제를 섞은 경우
- 간접정범, 교사범, 소송사기, 직권남용감금의 행위자 구조를 섞은 경우
- 횡령죄에서 보관자 지위와 재물 객체를 한 번에 뭉개 판단한 경우
- 공동피고인 진술, 경찰ㆍ검사 피의자신문조서, 전문진술의 증거능력을 섞은 경우
- 통신제한조치, 통신자료, 통신사실확인자료의 절차를 혼동한 경우
- 전자정보 압수범위에서 휴대전화와 원격지 서버를 영장 문언 안에 과도하게 포함한 경우
- 특경법 이득액 기준, 저당권설정 약정 배임, 불가벌적 사후행위, 항소권회복을 혼동한 경우

## 15회 변시 풀이 사용법

문항을 풀릴 때는 해당 `qNNN_과목.md` 전체를 넣되, 아래 우선순위를 지키는 프롬프트를 함께 주는 것이 좋습니다.

1. `v3 수동 보강 포인트`가 있으면 이를 가장 먼저 적용합니다.
2. 그 다음 `선지 분해`를 기준으로 각 선지를 독립 판단합니다.
3. 자동으로 붙은 `판례 근거`와 `선지별 근거 후보`는 보조자료로만 사용합니다.
4. 자동 후보와 수동 보강이 충돌하면 수동 보강을 우선합니다.
5. 최신 현행법 조문과 시험 문항의 사건 당시 조문이 다를 수 있으므로, 문항이 특정 구 조항을 전제로 하면 그 구 조항의 헌재ㆍ대법원 결론을 우선합니다.
6. 조합형 문제는 전체 인상으로 고르지 말고 `ㄱ/ㄴ/ㄷ/ㄹ/ㅁ`마다 O/X 표를 먼저 만든 뒤 선택지 번호로 변환합니다.

## 민사법 처리

민사법 70문항은 이번 피드백에서 별도 오답 목록이 없어서 v2 본문을 유지했습니다. 다만 v3 폴더 안에 그대로 포함되어 있으므로, 15회 전체 150문항 평가에는 이 폴더 하나만 사용하면 됩니다.

민사법 오답이 새로 발견되면 같은 방식으로 처리합니다. 새로 생성하지 않고 해당 문항 파일에 `v3 수동 보강 포인트`를 추가하거나, 이미 배포된 v3를 보존해야 하면 v4 폴더를 새로 만들어 같은 절차를 반복합니다.

```text
마지막에 선택지 조합으로 번호를 고른다.
```
