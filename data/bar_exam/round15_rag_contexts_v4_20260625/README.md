# 제15회 변호사시험 RAG 컨텍스트 v4

작성일: 2026-06-25

이 폴더는 `round15_rag_contexts_v3_20260622`를 기준으로 복사한 뒤, 제15회 변호사시험 평가에서 남은 오답 10문항을 다시 읽고 보강한 v4입니다. v3에서 잘 잡고 있던 보강은 유지했고, 실제 오답 원인으로 드러난 세부 법리와 조합형 선택지 매칭 위험을 추가로 보강했습니다.

문제와 선택지는 포함하지만, 문항별 정답 번호나 채점표는 넣지 않았습니다. 모델이 정답을 외워 맞히는 것이 아니라, 문제 문구와 공식 법리 컨텍스트로 결론을 도출하게 하려는 목적입니다.

## 생성 방식

1. `data/bar_exam/round15_rag_contexts_v3_20260622` 전체를 `data/bar_exam/round15_rag_contexts_v4_20260625`로 복사했습니다.
2. 모든 문서 제목의 버전 표기를 `v4`로 바꾸었습니다.
3. 제15회 평가 오답 10문항의 RAG 파일을 직접 열어 문제 문구, 선지 구조, 기존 보강 내용을 다시 확인했습니다.
4. 데이터 보강이 이미 충분했던 문항은 그대로 두고, 데이터가 부족하거나 모델이 흔들릴 수 있는 문항에 `v4 수동 보강 포인트`를 추가했습니다.
5. 로컬 `legalize-kr`, 로컬 `../precedent-kr`, 국가법령정보센터, 대법원/헌법재판소 공식 자료를 우선해 법리 분기를 정리했습니다.

- 한정위헌결정 이후 재심기각결정과 원 유죄판결의 재판소원 허용 여부를 구분했습니다.
- 헌법소원 공동소송참가가 독립한 청구 성질을 가져 청구기간 내 이루어져야 한다는 점을 명시했습니다.
- 공동피고인 신문 진술, 경찰 피의자신문조서, 변론 분리 후 증인적격, 전문진술 예외를 각각 분리했습니다.
- 포괄일죄 병합 후 추가기소를 기계적으로 공소기각판결로 처리하면 안 된다는 점을 보강했습니다.
- 확정판결 후 10년 소멸시효가 완성된 소유권이전등기청구권에 기한 등기의 효력을 명확히 했습니다.
- 채권자대위소송 직접 지급 판결 후 압류명령/전부명령의 효력, 재소금지 효과를 보강했습니다.
- 전손 건물 손해배상에서 시가와 철거비용을 자동 합산하면 안 된다는 점을 보강했습니다.
- 보증인, 물상보증인, 채무자 소유 부동산의 제3취득자를 구분하도록 보강했습니다.

## 사용 우선순위

문항을 풀릴 때는 해당 `qNNN_과목.md` 전체를 넣되, 아래 순서를 지키게 해야 합니다.

1. 문제 방향을 먼저 확정합니다: `옳은 것`, `옳지 않은 것`, `O/X 조합`.
2. `v4 수동 보강 포인트`가 있으면 자동 판례 후보보다 우선 적용합니다.
3. 각 지문을 `ㄱ/ㄴ/ㄷ/ㄹ/ㅁ` 단위로 독립 판단하고, O/X 표를 먼저 만듭니다.
4. 자동으로 붙은 `판례 근거`와 `선지별 근거 후보`는 보조자료로만 사용합니다.
5. 자동 후보와 수동 보강이 충돌하면 수동 보강과 공식 URL을 우선합니다.
6. 마지막에 산출된 O/X 집합을 선택지 번호와 하나씩 대조합니다.
7. 선택한 번호의 지문 집합이 산출된 집합과 정확히 일치하는지 최종 검산합니다.
